## Starting a New Project

A new Project, will start with no observations, the CoMapeo Categories, and default Background Map. 

:::note 👣
### Step by Step

***Step 1:*** Go to the <img src="/images/notion/351bd29be717f58fba4061f4d5ef0db5508de31bd77417f31c2248b9f6cbbdee.jpg" alt="three-line-menu-black" className="emoji" style={{display:"inline",height:"1.2em",width:"auto",verticalAlign:"text-bottom",margin:"0 0.1em"}} />**Menu**.

***Step 2:*** Tap on <img src="/images/notion/2dc5f8d1ce7cb4fc3056d93376d473bed776c782a82ce25d64e4cf658571a316.png" alt="app-icon-comapeo-participant" className="emoji" style={{display:"inline",height:"1.2em",width:"auto",verticalAlign:"text-bottom",margin:"0 0.1em"}} /> **Collaborate**.

***Step 3:*** Select <img src="/images/notion/77ddbc4137798bed6b6b838cdfc22c990548dd8dc643056e500ffb59b0eb2b1b.png" alt="app-icon-comapeo-coordinator" className="emoji" style={{display:"inline",height:"1.2em",width:"auto",verticalAlign:"text-bottom",margin:"0 0.1em"}} /> **Start New Project.**

***Step 4:*** Add a **project name** and continue

***Step 5:*** Select a <img src="/images/notion/62edee383fbea1a2a7a9491250fb416621311f73aebf97c893acc4618da3263c.jpg" alt="-app-icon-comapeo-project-stats" className="emoji" style={{display:"inline",height:"1.2em",width:"auto",verticalAlign:"text-bottom",margin:"0 0.1em"}} /> **Project Statistics** option. This can be changed in Coordinator Tools

***Step 5:*** Your new project is ready! 

:::

![image](assets/f0d994c90fe2da23b55c303f59b58be848be1a4359b94831f6635610037e935d.jpg)

:::note 💡 Tip
The project that you started when first onboarding onto CoMapeo will still be available go back to

:::

The device that creates the New Project is the Coordinator and has access to new menu options. <img src="/images/notion/2dc5f8d1ce7cb4fc3056d93376d473bed776c782a82ce25d64e4cf658571a316.png" alt="app-icon-comapeo-participant" className="emoji" style={{display:"inline",height:"1.2em",width:"auto",verticalAlign:"text-bottom",margin:"0 0.1em"}} /> Teams and <img src="/images/notion/77ddbc4137798bed6b6b838cdfc22c990548dd8dc643056e500ffb59b0eb2b1b.png" alt="app-icon-comapeo-coordinator" className="emoji" style={{display:"inline",height:"1.2em",width:"auto",verticalAlign:"text-bottom",margin:"0 0.1em"}} /> Coordinator Tools will appear in the <img src="/images/notion/351bd29be717f58fba4061f4d5ef0db5508de31bd77417f31c2248b9f6cbbdee.jpg" alt="three-line-menu-black" className="emoji" style={{display:"inline",height:"1.2em",width:"auto",verticalAlign:"text-bottom",margin:"0 0.1em"}} />Menu

Go to 🔗 [Inviting Collaborators](/pt/docs/inviting-collaborators) for instructions on inviting new devices to the team

## Coordinator tools

### <img src="/images/notion/fa890f05ac62b8e70d4ea529146e19b878a79aa0bd5b35be1c0a217453bf80e8.png" alt="app-icon-comapeo-project-cards" className="emoji" style={{display:"inline",height:"1.2em",width:"auto",verticalAlign:"text-bottom",margin:"0 0.1em"}} /> Project info

- **Name** 

- **Description -** A description can be added to articulate the project purpose or objectives for all teammates to refer to as needed

- **Color**

Go to 🔗 [Using a Remote Archive](/docs/using-a-remote-archive)
